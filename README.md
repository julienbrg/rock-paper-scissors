# Rock Paper Scissors

Privacy-preserving on-chain Rock Paper Scissors game.

- [Main contract](https://github.com/julienbrg/rock-paper-scissors/blob/main/contracts/Game.sol)
- [Zama docs](https://docs.zama.ai/homepage)

### Install

```bash
pnpm i
```

## Test

```bash
pnpm test:game
```
